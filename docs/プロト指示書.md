# プロト指示書:マンジャロゲーム 30秒プロトタイプ

作成:2026-07-22 / 企画書.md の設計に基づく。**Claude Code にはこのファイルの内容だけ渡す**(テーマ・啓発意図は書かない=判定を濁らせないため)

---

## この指示書の使い方

- 下の「Claude Code への指示」ブロックをそのまま貼る
- テーマ(糖尿病・マンジャロ・啓発)は意図的に書いていない。プロトの判定は「テーマ抜きで面白いか」なので、コアメカニクスだけを曖昧さゼロで渡す
- 動いたら、末尾の「CONFIG 初期値」を起点に数値を振って手触りを調整する

---

## 判定基準(自分の中だけで握る・Claude Codeには伝えない)

- テーマの話を一切せず30秒遊んで「**もう一回、さっきより速く**」と自分から思うか
- 高血糖に近い密集区間で「**取りたくない!**」と口に出すか
- 女性キャラを前に**一瞬迷うか**(無視して直進できるなら配置か効果が弱い)

→ 出なければ、この案も捨ててよい(1ステージ分の損で済むよう最小構成にしてある)

## Claude Code への指示(ここから下をそのまま貼る)

3Dランアクションのプロトタイプを作ってほしい。テーマや物語は不要、コアメカニクスの検証だけが目的。30秒で1プレイが終わる規模でいい。

### 技術
- Three.js + 素のJavaScript、単一HTMLで動くもの(ローカルでブラウザを開けば遊べる形)
- アセットは全部プリミティブ(box / sphere / plane / capsule)で仮。見た目は問わない
- **調整する数値は全てファイル冒頭の `CONFIG` オブジェクトに定数化**。マジックナンバーを散らさない

### 視点・操作
- 3人称背面視点。自機は前方へ自動で走り続ける
- 操作は左右移動のみ(←→ / A・D)。3レーン制でいい
- ボタン1つ(スペース)=「注射」。効果は後述

### コアメカニクス:血糖値(0〜100)
- 画面に血糖ゲージを常時表示。初期値50
- 毎秒 `CONFIG.drainPerSec` で自然減少
- **基礎の走行速度は血糖値が「安定域」の中央に近いほど速く、外れるほど遅い**。ここが最重要:
  - 安定域を `CONFIG.stableMin`〜`CONFIG.stableMax`(仮 40〜60)とする
  - その中央(50)で最高速、上下に外れるほどリニアに減速
  - 例:血糖50=速度100%、血糖30 or 70=速度60%、血糖10 or 90=速度20%程度。CONFIGでカーブを調整できるように
- **血糖 0以下 = 低血糖でゲームオーバー**(下限。自然減少があるので食べ続けないと自然に下限へ向かう)
- **高血糖カウントダウン**:血糖が `CONFIG.hyperThreshold`(仮80)を超えたら画面に警告+カウントダウン開始。`CONFIG.hyperGraceSec` 秒(仮3秒)以内に安定域(stableMax以下)へ戻せなければゲームオーバー。安定域に戻ればカウントダウンはリセット
  - ※重要:高血糖では減速するが、減速だけだと「遅い→食べ物を拾わない→自然に助かる」で上限死が機能しなくなる。カウントダウンで「自分で血糖を下げる行動(注射/食べない)を取らないと死ぬ」状態を作るのが狙い
- ゲージは3色ゾーンで表示:安定域=緑、その外=黄、危険域(端)=赤点滅

### 食べた瞬間ブースト(食べる報酬)
- 食べ物を取った瞬間、`CONFIG.foodBoostDuration` 秒間(仮1.5秒)だけ速度に `CONFIG.foodBoostMult` 倍(仮1.4)のブーストがかかる
- **このブーストは基礎速度(血糖ベース)とは別レイヤー**。血糖がどこにあっても食べれば発生する(=「食べると気持ちいい」を血糖と切り離す)
- ブーストが切れれば速度は基礎速度に戻る。連続で食べればブーストは重ねずリフレッシュ(持続時間を上書き)でよい
- ※高血糖でいる"状態"は速くしない。速いのはあくまで食べた"瞬間"だけ。基礎速度は血糖が中央から外れるほど遅いまま

### 食べ物(アイテム)
- レーン上に流れてくる丸。取る=血糖 `CONFIG.foodGain`(仮 +15)
- 取り逃しても直接のペナルティなし(ただし放置すれば自然減少で低血糖に向かう)
- **配置で「取りたくないのに取ってしまう」を作る**:一部区間は全レーンに食べ物を置き、完全回避を難しくする(1レーンだけ空ける等)。吸着や自動取得はしない(必ずプレイヤーの移動で取る/取らないが決まるように)

### 注射(スペース)
- 押すと以後 `CONFIG.shotDuration` 秒間(仮7秒)、食べ物の摂取量が `1/3`(+15 → +5)になる
- クールタイム `CONFIG.shotCooldown` 秒(仮7秒)。ボタン脇に「あと何秒で撃てるか」を表示
- クールタイム中は押しても不発(連打不可)

### 障害物:女性キャラ(仮:赤いカプセル等でいい)
- レーン上に立っている。ぶつかる=**`CONFIG.lockDuration` 秒間(仮7秒)注射ボタンがロック**(押せない)。ロック残り時間をUI表示
- 減速や血糖ダウンは付けない(ペナルティは注射封じ一本)
- 密集地帯(食べ物が全レーンに来る区間)の**手前**に配置し、「よけてから注射」か「注射してから突っ込む」の判断が生まれるようにする

### クライマックス:ゾーン(集中状態)
- **血糖を安定域(stableMin〜stableMax)内に保ち続けると、専用ゲージが `CONFIG.zoneChargePerSec` で溜まる**。安定域を外れると蓄積が止まる(または `CONFIG.zoneDecayPerSec` で減る)
- ゲージ満タンで `CONFIG.zoneDuration` 秒間(仮5秒)「ゾーン」発動:**この間だけ速度が `CONFIG.zoneSpeedMult` 倍(仮1.5)**。演出はエフェクト仮でいい
- 重要:ゾーンは「血糖を高くする」ではなく「**安定を保った巧さ**」への報酬。高血糖や乱用では入れない設計にすること

### 勝敗・UI
- コース終端にゴール。到達タイムを表示=スコア。早いほど良い
- ゲームオーバー(低血糖/高血糖)=失敗。リトライは即・コース頭から
- 画面に常時表示:血糖ゲージ(3色)/注射クールタイム残り/注射ロック残り/ゾーンゲージ/経過タイム/**高血糖カウントダウン(発動中のみ大きく警告表示)**

### CONFIG に必ず出す数値(初期値のたたき台)
```
drainPerSec       : 3      // 血糖の毎秒自然減少
stableMin         : 40     // 安定域 下限
stableMax         : 60     // 安定域 上限
hyperThreshold    : 80     // この血糖を超えるとカウントダウン開始
hyperGraceSec     : 3      // 高血糖から安定域に戻す猶予(秒)。超えると死
foodGain          : 15     // 食べ物1つの血糖上昇
foodBoostMult     : 1.4    // 食べた瞬間の速度ブースト倍率
foodBoostDuration : 1.5    // 食べた瞬間ブーストの持続(秒)
shotDuration      : 7      // 注射の効果持続(秒)
shotEffect        : 0.333  // 注射中の摂取倍率(1/3)
shotCooldown      : 7      // 注射クールタイム(秒)
lockDuration      : 7      // 女性接触時の注射ロック(秒)
zoneChargePerSec  : 20     // 安定維持中のゾーンゲージ蓄積(%/秒)
zoneDecayPerSec   : 10     // 安定を外れた時の減少(%/秒)
zoneDuration      : 5      // ゾーン発動時間(秒)
zoneSpeedMult     : 1.5    // ゾーン中の速度倍率
courseLengthSec   : 30     // コース1本の想定プレイ時間
```

まずこの1コース・30秒が動く最小構成を作って。動いたら数値をCONFIGで振って手触りを調整したい。

## 貼り終えたあと(自分用メモ)

- 数値は「毎日調整」前提。面白い設定が出たら CONFIG の値をこのファイルに追記して履歴を残す
- ジャンプ・4ステージ・女性の「奪う」演出は**判定を通してから**足す。プロトには入れない
