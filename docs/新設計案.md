# 新設計案 — マンジャロ日本縦断

先生の敲き(2026-07-31)を受けた設計。旧版(`processing/manjaro/`)は残したまま、別で作る。

---

## 0. このゲームが問うこと

**「速く走りたい」という欲が、薬への依存を生む。**

タイムアタックである以上、プレイヤーは必ず速さを求める。速く走れば血糖を消費し、消費すれば食べたくなり、食べれば高血糖になり、薬に頼ることになる。**ゲームの目的そのものが、プレイヤーを乱用へ導く。**

だからゴールの問い「あなたはこの薬を、何のために使いましたか」に、プレイヤーは自分の答えを持っている。

---

## 1. 全体の流れ

```
沖縄 25秒 → 【フェリー】判定・休憩・成績
本州西 25秒 → 【フェリー】
本州東 25秒 → 【フェリー】
北海道 25秒 → 日本縦断達成
```

走行合計 100秒 + フェリー4回。

### ステージ構成

各ステージ内で **1.5倍まで加速**し、フェリーごとに**開始速度が上がる**。
休憩のたびに速度が一度落ちるので、いきなり手に負えなくならない。

| ステージ | 開始速度 | 終了速度 | 長さ | 無減速タイム |
|---|---|---|---|---|
| 沖縄 | 70 | 105 | 2,158 | 25.0秒 |
| 本州西 | 85 | 128 | 2,620 | 25.0秒 |
| 本州東 | 100 | 150 | 3,083 | 25.0秒 |
| 北海道 | 115 | 173 | 3,545 | 25.0秒 |

最高速は沖縄開始の 2.46 倍。

## 2. 血糖値(ゲージは1本だけ)

**エネルギーゲージは作らない。** 2本あると走りながら両方を見ることになり、判断が散る。
「食べられなくなる」ことは、血糖値の低い側でそのまま表せる。

| 動き | 効果 |
|---|---|
| **走る** | 血糖が減る。**速いほど多く消費する** |
| **食べる** | 血糖が増える |
| **緑(安定域)を保つ** | ゾーンが溜まる |

### 上下から挟まれる

```
        マンジャロを打たない
              ↓
        食べすぎる → 高血糖
      ───────────────────────
        血糖値ゲージ(緑を保つ)
      ───────────────────────
        食べても上がらない → 低血糖
              ↑
        マンジャロを打つ
```

---

## 3. マンジャロ

### 週1回の薬であることを守る

現実のマンジャロは**週1回の持続性の薬**であり、血糖が上がった瞬間に打つ薬ではない(それはインスリンの役割)。

**1ステージ = 1週間**とみなし、**打てるのは各ステージ1回だけ**。
ただし**いつ打つかは自由**(走行中にスペース)。現実でも「今週の分をいつ打つか」は自分で決める。

| 項目 | 内容 |
|---|---|
| 打てる回数 | **1ステージ1回** |
| タイミング | 走行中、好きなときに |
| 効果 | **5〜8秒間、食べ物が無効になる**(数値は仮) |
| 血糖への直接影響 | **なし**(薬が血糖を動かすわけではない) |
| 効果中の食べ物 | **灰色になって残る。触れても素通りする** |
| リスク | 効果中は血糖が**下がる一方**。早く打ちすぎると低血糖 |

### 食べ物を「消す」のではなく「無効化する」

薬が食べ物を消滅させるのは非現実的。**食べ物はその場に残り、灰色になる。**
触れても消費されず、素通りする。「そこにあるのに、食べたいと思わない」= 食欲抑制の表現。

### 判断は「打つか」ではなく「いつ打つか」

- **早く打ちすぎる** → 残りずっと食べても回復せず、低血糖へ
- **遅すぎる** → その前に食べすぎて高血糖
- **打たない** → 食事の管理だけで乗り切る

## 4. 減速・加速・失敗

### 減速要素

| きっかけ | 備考 |
|---|---|
| **高血糖のカウントダウンが切れた** | **旧版では即ゲームオーバーだった** |
| **低血糖の下限に到達** | **旧版では即ゲームオーバーだった** |
| **岩(障害物)に接触** | 新規 |

**倒れてもやり直しにならない。** 減速して、そのまま走り続ける。
これで「失敗しても最後まで通しで遊べる」ようになる(発表で見せるときに有利)。

### 加速要素

| きっかけ | 備考 |
|---|---|
| **ステージ内の自動加速** | 常時。1.5倍まで |
| **エナジードリンク** | 加速するが**血糖が跳ね上がる**。新規 |

**エナドリが誘惑の要。** 時間が押しているとき目の前にある。取れば間に合う。でも血糖が跳ねて、薬に手が伸びる。
配置は「失敗しそうな地点の手前」(先生の提案)。

### 制限時間

**32秒**(仮)。1回の減速で約2秒失うとすると:

| 減速回数 | タイム | 判定 |
|---|---|---|
| 0回 | 25.0秒 | 余裕 |
| 3回 | 31.0秒 | ギリギリ間に合う |
| **4回** | **33.0秒** | **間に合わない** |

**超過したら、そのステージの最初から。**

| やり直しで戻るもの | |
|---|---|
| ステージのタイム | リセット |
| 血糖値 | **50に戻す** |
| 食べ物・岩 | 復活(同じ配置) |
| マンジャロ | **未使用に戻る** |
| **総タイム** | **やり直した分も加算する** |

総タイムに加算する理由:タイムアタックである以上、かかった時間は全部かかった時間。
加算しないとやり直しが無料になり、制限時間の意味が薄れる。
ゴール画面には**やり直し回数**も別に表示する。

## 5. コース上のもの

| | 内容 |
|---|---|
| **食べ物** | 血糖が上がる。種類で差をつける(軽い/重い) |
| **エナジードリンク** | 加速 + 血糖が大きく上がる |
| **岩** | ぶつかると減速 |
| ~~女性キャラ~~ | **廃止** |

**女性キャラの廃止は企画書からの変更点。** 走行中の薬の扱いが変わり、「注射をロックする」仕組みが噛み合わなくなったため。「薬を奪う人々」というテーマ要素が1つ無くなるので、聞かれたときの理由を用意しておくこと。

**用語の注意:** 旧版の「壁」(食べ物3個並び・マンジャロで消す)は**廃止**。新しく足す「岩」とは別物なので、混同しないよう「障害物=岩」と呼ぶ。

## 6. フェリー(チェックポイント)

各ステージの終わりに港へ着く。**ここで手が止まる = 休憩**(先生が2回要望)。

- そのステージの成績(タイム・食べた数・マンジャロを使ったか)
- 次のステージへ

## 8. 先生の指摘との対応

| 指摘 | 対応 |
|---|---|
| 乱用エリアは矛盾では? | **マンジャロ強制の壁を廃止** |
| 自分で打つ選択が無くても良いのでは | **選択は残す**。無くすと薬が空気になるため。ただし強制はしない |
| 安定期だったら走れるはなぜ / 走ったら乱高下 | **速く走るほど血糖を消費する** |
| 食わずに運動したら血糖値下がってく | 同上 |
| チェックポイント / タイム加算 | **フェリー + 制限時間** |
| エナドリで加速→血糖上がる | **実装する** |
| 失敗しそうな地点の手前にエナドリ | 配置ルールとして採用 |
| エネルギーのメモリ増やしたら | **採用しない。**2本あると判断が散る。低血糖側で表せる |
| ご飯の種類増やそう | **軽い/重い/エナドリ** |
| 障害物あっても良いかも | **岩** |
| もう少し遅くても良い | 速度を下げた(旧版は最高196、新版は最高173) |
| 休みをちょうだい(2回) | **フェリー** |
| もっと俺のロジックを超えるものを | **「速さへの欲が依存を生む」という一本の筋** |

## 9. 実装の段階(各段階で遊べる状態を保つ)

**旧版 `processing/manjaro/` は凍結。新版は別フォルダで作る。**
どの段階で止めても、そこまでで完結していること。

| 段階 | やること | 止めた場合 |
|---|---|---|
| **0** | 旧版をコピー | 旧版と同じ。動く |
| **1** | 壁の廃止 + 倒れる=減速 | **旧版より提出物として強い**(先生の核心に回答済み) |
| **2** | 4ステージ + フェリー | 休憩が入り、日本縦断が明確に |
| **3** | 制限時間 + ステージやり直し | 緊張が生まれる |
| **4** | マンジャロを1ステージ1回に + 無効化方式へ | **新設計の核が完成** |
| **5** | 岩 | 減速要素が揃う |
| **6** | 速度で血糖の消費が変わる | ロジックが強くなる |
| **7** | エンディングの分岐 | 問いに答えが返る |
| **8** | エナドリ | 誘惑が完成する |
| 9 | 食べ物の種類 | 素材が要る |

**引き返す時刻を先に決めること。** 決めておかないと粘って両方中途半端になる。
